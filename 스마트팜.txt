1. 첫번째컨베이어

cam1(라파1)에 트레이가 인식되면 start_falg = 1, stm32에게 uart로 전송하면 직교로봇 홈동작, 후 컨베이어 구동.
트레이가 적외선에 인식되면 ir1 = 1, 컨베이어 정지하고, 씨앗 파종.
파종 후 적외선 안걸릴때까지 컨베이어 구동, 적외선이 안걸릴때까지 이동 끝나면 scara flag = 1이 되도록 아두이노(스카라로봇)한테 전송.
스카라가 동작시작하면(트레이를 들었을 시점) 다시 stm한테 scara flag = 0 이 되게끔 uart 전송, 그럼 다시 start flag = 0, ir = 0 이 됨, 그러면 첫번째 컨베이어 상태 초기화 됨.
스카라 로봇은 트레이를 발아실로 옮김

2. 발아실+수경재배실

발아실 트레이에서 싹이 트기 시작하면 cam2(라파2)을 통해 인식. start2_flag = 1 이 되도록 스카라로봇(atmega)에게 문자열 전송. 스카라로봇이 트레이를 발아실->수경재배실로 옮김. 옮기는 동작이 끝나면 start2_flag = 0.


3. 수경재배실+두번째컨베이어

수경재배실에서 성장이 완료된 식물을 cam3(라파3)을 통해 인식. start3_flag = 1이 되게 스카라로봇(atmega)에게 문자열 전송. 스카라로봇이 트레이를 수경재배실에서 두번째 컨베이어(stm)로 옮겨놓으면, atmega가 stm에게 sec_con_flag = 1이 되도록 문자열 전송. 컨베이어 구동하고 적외선센서에 닿으면 정지(이때 ir2 = 1),  후 직교로봇이 트레이를 눌러 고정시킴. 고정이 다 되면 push_flag = 1이 되고, 스카라로봇과 매니퓰레이터(opencr)가 수확을 할 수 있도록 harvest_flag = 1 이 되도록 스카라로봇과 매니퓰레이터에게 문자열을 보냄. 둘 다 수확이 끝나면 stm에게 push_flag = 0이 되도록 문자열 전송. 그럼 사이클 초기화.
직교로봇은 z축만 존재하고,  sec_con_falg = 1일때 cw로 구동해서 리밋스위치를 한 번 찍고 내려가서 호밍을 하고, 컨베이어가 정지하면(ir2 = 1) ccw로 구동해 트레이를 고정시킴
 

라파와 stm, 라파와 opencr, 라파와 아두이노, stm과 아두이노 등은 uart통신으로 진행하고 라즈베리파이끼리는 ros통신. 가장 상위에 pc가 있고 pc에서 웹페이지로 전체적인 상황을 보여줄 수 있도록 함. pc<->라파<->제어기 로 흐름이 진행될 것 같음.

첫번째 컨베이어- 캠에서 트레이 인식하면 stm32한테 uart통신 -> stm32 직교로봇 호밍, 컨베이어구동 -> ir 감지되면 컨베이어 멈추고 파종 -> 파종 후 ir 감지 안 될때까지 컨베이어 이동 ->  후 스카라 로봇이 uv실로 옯기기 위해 stm32에서 uart통신

스카라로봇- 통신받으면 트레이를 들어올려 uv실로 옯김, 발아가 다 된 트레이를 수경재배실로 옮김, 성장이 끝난 트레이를 두번째 컨베이어로 옮김. 수학 도중 새 트레이가 들어와서 파종되면 트레이를 uv실로 옯기는 작업을 먼저 수행함, 만약 수확 작업 중이어도 uv실로 옮기는 동작이 우선. 수확 도중 첫번쨰 컨베이어의 트레이를 uv실로 옮기고 다시 수확을 진행하는 등의 알고리즘이 필요함.

두번째 컨베이어- 성장이 완료된 트레이가 스카라 로봇을 통해 두번째 컨베이어에 올려지면 컨베이어가 구동하다가 ir센서 감지되면 멈춤 -> 직교로봇 하강해서 트레이 고정 -> 매니퓰레이터와 스카라 로봇이 수확.

매니퓰레이터- 두번째 컨베이어의 직교로봇이 트레이를 고정시키면 그떄부터 수확 시작


스카라 로봇이 트레이를 uv실로 옯기는 동작과 수확 동작 알고리즘을 짜야 함.
매니퓰레이터의 수확 알고리즘을 짜야 함.
전체적인 통신 통합 어떻게 할지도 짜야 함.
